# @eliware/log specification

This directory defines the mandatory public behavior of `@eliware/log`. The
requirements are normative; explanatory implementation details are secondary.

## Contents

- [Requirements](requirements.md) — public exports, configuration, output, and safety requirements.
- [Out of scope](out-of-scope.md) — behavior this package does not promise.

See the [root README](../README.md) and [test guidance](../docs/safety-and-troubleshooting.md)
for usage and validation details.
