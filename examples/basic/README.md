# Basic example

This runnable example logs placeholder metadata without external I/O or
credentials.

## Prerequisites

Use Node.js 26 or newer and install dependencies from the repository root with
`npm ci`.

## Usage

From the repository root, run `npm ci` and then:

```bash
node examples/basic/example.mjs
```

It prints one local info log line.

## Expected result

The command prints a single info-level log line containing `Basic example` and
the placeholder metadata.
